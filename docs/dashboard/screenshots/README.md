# Screenshots

Drop images here and reference them from a decision record in
`docs/decisions/decisions.json`:

```json
"artifacts": [
  { "type": "screenshot", "path": "screenshots/D007-before.png", "caption": "..." }
]
```

`path` is relative to `docs/dashboard/`. Name files `<decision-id>-<slug>.png` so the
Markdown log and the dashboard resolve them identically.

No credentials, tokens, private client data, or personal information in images — this
repository is public.
